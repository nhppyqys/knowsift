# 案例：把“网上都在讲的英语学习方法”变成一份分层知识文档

这个案例演示 KnowSift 在完整工作流中的位置。所有来源均为虚构样本，目的是验证分类与防越界行为。

## 用户原话

> Agent，你去看看网上关于成年人怎样学英语的内容，最后给我一份真正可信、能指导学习的文档。

## 第一步：外部 Agent 负责采集

外部 Agent 找到一份研究摘要、三段视频字幕和一个课程销售页，保留原文、来源类型、链接与时间戳，写入 `source-bundle.json`。

这一步不由 KnowSift 完成。它不搜索 Bilibili、YouTube，也不下载视频。

## 第二步：不要直接总结，先拆成说法

材料被拆为六条彼此独立的说法：

1. 研究中的分散复习比较结果；
2. 讲师甲说了什么；
3. 讲师乙说了什么；
4. 学习者丙自述了什么；
5. “成年人绝对不应该背单词”是否可当作事实；
6. “任何人每天十分钟，三十天达到母语水平”是否可当作事实。

注意：第 2 条和第 5 条不是一回事。视频原文可以证明“讲师甲确实这样说过”，却不能单独证明“讲师甲说的对所有成年人都是真的”。

## 第三步：逐条编译

| 说法 | 证书结果 | 原因 |
|---|---|---|
| 研究内的分散复习结果 | `ADMIT` | 原文直接支持，并强制保留研究范围 |
| 讲师甲的主张 | `ADMIT` 的 `OBSERVE` | 只准入“讲师甲说过” |
| 讲师乙的主张 | `ADMIT` 的 `OBSERVE` | 只准入“讲师乙说过” |
| 学习者丙的自述 | `ADMIT` 的 `OBSERVE` | 只准入个人自述 |
| 绝对不要背单词 | `HOLD` | 两个来源互相冲突，缺少裁定证据 |
| 三十天达到母语水平 | `HOLD` | 销售页只能证明自己做过承诺，不能证明效果 |

## 第四步：生成给人看的文档

最终文件是 [RESULT.md](RESULT.md)。它没有丢弃观点和故事，而是把它们放回正确身份：

- 研究支持的内容进入知识区；
- 某人说过的话进入观点或自述区；
- 相互冲突和证据不足的说法留在争议区；
- 每条内容都能回到来源和证书。

这份文档的价值不是“信息更多”，而是读者不用自己猜每句话到底有多可信。

## 运行

在仓库根目录执行：

```bash
python3 examples/learning-english/generate_demo.py
```

生成脚本会重建来源包、六条说法、六份证书、文档计划和最终 Markdown。任何层级与证书不匹配，生成都会失败。
